General Equilibrium Conditions

For a rigid body to be in complete three-dimensional equilibrium:

ΣFx = 0   ΣFy = 0   ΣFz = 0

ΣMx = 0   ΣMy = 0   ΣMz = 0

Three force equations and three moment equations must be satisfied.
